# java-racingcar-precourse

---
mvc 패턴을 이용한 자동차 경주

> 초간단 자동차 경주 게임을 구현한다

## 구현 기능 목록

--- 

### Main

- **Application**
    - [ ] RacingCarController 통해 자동차 경주를 실행한다.

### Model

- **Car**
  > 자동차 경주에서 자동차 역할을 담당한다.
    - [ ] 자동차 이름을 갖는다.
        - 이름이 5자를 초과하면 오류를 반환한다.
        - 이름이 비어있으면 오류를 반환한다.
        - 이름에 빈 문자열이 있으면 오류를 반환한다.
    - [ ] 자동차의 이동 거리를 갖는다.
    - [ ] 자동차의 이름과 이동거리를 보여준다.

- **Cars**
  > `Car`도메인에 대한 일급 컬렉션이다.
    - [ ] 자동차 각각의 이동 거리를 정한다.
    - [ ] 자동차의 우승을 알려준다.

- **RandomMovement**
  > 무작위 값을 받아 전진의 여부를 반환한다.
    - [ ] 자동차의 개수를 인자로 받아 해당 개수만큼 전진의 여부를 리스트로 반환한다.
        - 0에서 9 사이에서 무작위 값을 구한 후 무작위 값이 4 이상일 경우 true를 반환한다.

### View

- InputView
  > 사용자의 문자열을 입력하는 UI 역할을 담당한다.
    - CarInputView
        - [ ] `경주할 자동차 이름을 입력하세요.(이름은 쉼표(,) 기준으로 구분)`문자열을 출력한다.
        - [ ] 사용자로부터 자동차 이름을 입력받는다.
        - [ ] 빈 문자열을 입력받으면 오류를 반환한다.
    - AttemptInputView
        - [ ] `시도할 횟수는 몇 회인가요?` 문자열을 출력한다.
        - [ ] 숫자가 아니면 오류를 반환한다.

- OutputView
  > 자동차 경주에서 실행 결과를 출력하는 UI 역할을 담당한다.
    - ExecutionOutput
        - [ ] 각 횟수 별 실행 결과를 출력한다.
    - WinnerOutput
        - [ ] 최종 우승자를 출력한다

### Controller

- **RacingCarController**
  > 자동차 경주의 흐름을 제어한다.
    - [ ] `InputView`로 사용자의 입력을 받는다.
    - [ ] 자동차 경주 로직을 실행한다.
    - [ ] `OutputView`로 결과를 출력한다.
